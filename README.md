# Talent Bridges Forward

Build a responsive web application called TalentBridge – Skills to Opportunities.

The application should help skilled refugees showcase their abilities, connect with mentors, and find employment opportunities.

The six pages:
1. Home: A professional welcome page explaining the problem of skilled refugees struggling to find employment. Include a clear "Get Started" button routing to profile setup.
2. My Profile: Allow users to enter and edit their name, professional background, education, work experience, and skills.
3. Skills Portfolio: Allow users to showcase projects, certificates, and examples of their work. Clearly label skills as self-reported unless independently verified.
4. Opportunities: Display internships, remote jobs, fellowships, and training opportunities. Allow users to search and filter opportunities by skill and category. Include an apply modal with form.
5. Mentorship: Allow users to view mentor profiles and submit mentorship requests.
6. Dashboard: Display the number of registered profiles, listed opportunities, and mentorship requests. Make dashboard statistics update dynamically when users add profile info, projects, apply for opportunities, or submit mentorship requests.

Key requirements:
- Navigation: Fixed header with links to Home, My Profile, Skills Portfolio, Opportunities, Mentorship, and Dashboard, with smooth mobile hamburger menu.
- Design: Modern, clean, professional, simple, and beginner-friendly. Main colors: navy blue (#0F2942 / #1B365D), teal (#0D9488 / #14B8A6), and white.
- Fully responsive on both mobile phones and desktop computers.
- Simple, clear English throughout.
- Include realistic sample demo data so the application looks complete on launch.
- Clearly label sample opportunities, mentor profiles, and initial statistics as demo data.
- Make all forms, navigation, search, filters, and buttons fully functional.
- Save user information, applied opportunities, and mentorship requests in browser local storage so they remain after refreshing, and clearly explain to users that data is stored locally on the current device.
- Do not claim to officially verify refugee qualifications or work permits.
- Do not collect sensitive immigration documents or identification numbers.
- Prioritize a complete working MVP over complicated features or paid integrations.
